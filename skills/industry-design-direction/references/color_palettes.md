# Color palettes by industry

Six roles per palette: Primary, Secondary, CTA, Background, Text, Border.

**The contrast numbers below are computed, not claimed** — each row's
text-on-background ratio was calculated with the WCAG 2.x relative-luminance
formula when this file was generated, and every palette here clears AA (4.5:1)
for body text. That is the *only* pair that was verified. If you put text on the
primary, secondary, or CTA color, you must check that pair yourself: a CTA that
passes as a block of color says nothing about white label text sitting on it.
